# 통통 입자 여행 · 기체 안전 여행사

중학교 1학년 과학 「Ⅵ. 기체의 성질」 단원(2022 개정, 천재교육(정) 교과서 기준)을 9차시 동안 여행하듯 배우는 웹앱입니다.
학생은 여행사 가이드가 되어 여행지를 돌며, 성취기준마다 **본 것 → 잰 것 → 입자** 도장 3개를 모읍니다.

| 차시 | 여행지 | 내용 | 성취기준 |
|---|---|---|---|
| 1 | 그리스 유적지 | 압력의 뜻, 점토 실험 | 9과06-01 |
| 2 | 에어바운스 공원 | 기체의 압력과 입자의 충돌 | 9과06-01 |
| 3 | 센서 연구소 | 압력과 부피 측정, 그래프 | 9과06-02 |
| 4 | 하늘과 바다 | 보일 법칙을 입자로 해석 | 9과06-02 |
| 5 | 온도 실험실 | 온도와 부피 측정, 그래프 | 9과06-03 |
| 6 | 스키장과 온천 | 샤를 법칙을 입자로 해석 | 9과06-03 |
| 7~8 | 현지 체험 축제 | 부스 실험 (gas-booth 웹앱 연결) | 전체 |
| 9 | 가이드 자격시험 | 20문항, 오답 다시 풀기 | 전체 |

## 화면 방식
여행지에 들어가면 한 화면에 한 장씩 넘겨 보는 방식입니다(아라호와 같은 방식). ← → 키, 화면 밀기, 아래 버튼으로 넘기고, 빈칸을 열거나 질문에 답해야 다음 장으로 갑니다. 선생님 화면에 로그인한 기기에서는 잠금 없이 넘길 수 있습니다.

## 동기부여 장치
- 마일: 빈칸 열기, 예측, 문제 풀이, 실험 활동, 도장으로 모읍니다 (모두 맞히면 452마일).
- 등급 10단계: 수습 가이드부터 전설의 입자 가이드까지. Lv.6부터는 도장도 필요합니다.
- 여행 가방: 여행 스티커 8개와 배지 14개.
- 내 입자 꾸미기: 등급이 오르면 모자, 선글라스 등 6가지가 열립니다.
- 선생님 쿠폰 3개: `config.js`의 `COUPONS: false`로 끌 수 있습니다.
- 도장 찍기: 도장을 받으면 여권이 펼쳐지고 한 장 넘어간 뒤 도장이 찍힙니다(효과음 포함, 화면을 누르면 바로 닫힘). 기기의 '동작 줄이기' 설정을 켜면 애니메이션 없이 찍힌 모습만 보여 줍니다.
- 선생님 화면에 로그인한 기기에서는 마일이 쌓이지 않고, 여행지가 항상 첫 장부터 열립니다.

## 파일
- `index.html`, `style.css`, `app.js` : 웹앱
- `data.js` : 여행지 내용, 문항 39개, 스노클 과제 6개
- `sim3d.js` : 2·3·4·6차시 입자 모형의 3D 버전. 그 단계를 열 때만 불러오고, 3D를 못 쓰는 기기에서는 `app.js`의 2D 모형이 대신 나옵니다.
- `vendor/three.module.min.js` : 3D 엔진 Three.js r160 (MIT, `vendor/three.LICENSE`). 학교망에서 외부 사이트가 막혀도 되도록 저장소에 넣었습니다.
- `config.js` : 선생님 설정 (구글 시트 주소, 비밀번호, 부스 주소, 스노클 주소, 샤를 실험 부피 단위)
- `Code.gs` : 구글 시트 연동용 Apps Script

## 쓰는 법
1. GitHub Pages로 배포하면 바로 쓸 수 있습니다. 이때 기록은 학생 기기에만 저장됩니다.
2. 반 전체 그래프와 교사 화면의 반 현황을 쓰려면 `Code.gs`를 구글 시트에 붙여 배포하고, 주소를 `config.js`의 `API_URL`에 넣습니다. 자세한 순서는 웹앱의 선생님 화면 → 설정 방법에 있습니다.
3. 선생님 화면은 첫 화면 아래 링크로 들어갑니다. 처음 비밀번호는 `0000`입니다.

## 알아 둘 점
- 교사 비밀번호는 `config.js`에 그대로 적혀 있어 강한 보안이 아닙니다. 학생 정보는 반, 번호, 이름만 받습니다.
- 도장은 활동 완료 표시입니다. 성취수준 판단은 학생의 서술과 수업 관찰을 함께 보고 교사가 확정합니다.
- 자동차 타이어처럼 단단한 용기 소재, 두 요인이 함께 변하는 소재는 문항과 예시에서 뺐습니다.
